ImagActif : fabriquer une image pour votre support de classe

Mis à jour le 8 octobre 2026 · version de départ, à améliorer avec vos retours

Vous décrivez l'image voulue dans un formulaire guidé. ImagActif la fabrique avec une IA, la garde 30 jours, et conserve la description (le « JSON ») pour que vous puissiez refaire une image, en tirer une variante ou la réutiliser comme modèle. Vous restez l'auteur : c'est votre description, et c'est vous qui relisez le résultat.

1. Avant de commencer

  1. Créez un compte avec votre adresse professionnelle, puis cliquez sur le lien de confirmation reçu par e-mail. Si vous avez déjà un compte sur un autre outil PLAI, connectez-vous avec le même.
  2. À la première connexion, lisez et acceptez les règles d'utilisation (conservation, envoi du texte à BFL, essai).
  3. Essai gratuit de 3 jours : jusqu'à 10 images par jour. Un bandeau en haut de la page « Créer » indique ce qu'il vous reste.
  4. Après l'essai, ajoutez votre propre clé BFL (voir le point 6) pour continuer à créer des images. Vos images et vos JSON restent consultables.

2. Créer une image

  1. Ouvrez l'onglet Créer.
  2. Remplissez au minimum le sujet principal, par exemple « Un chat roux qui dort sur le rebord d'une fenêtre d'école ». Sous chaque champ, un texte explique ce que la saisie change.
  3. Précisez, si vous le souhaitez, le style, la palette, le cadrage, le point de vue, l'arrière-plan et la lumière. Plus c'est concret, moins l'IA improvise.
  4. Gardez « pas de texte dans l'image » dans À éviter : les IA écrivent mal. Ajoutez votre texte dans votre document.
  5. Choisissez le format selon l'endroit où l'image sera placée (carré, paysage, portrait…).
  6. Cliquez sur Créer l'image et patientez 10 à 40 secondes. Vous pouvez rester sur la page.
  7. Relisez l'image avant de l'utiliser. Si elle ne convient pas, modifiez la description et recommencez.

Détails avancés (facultatif). Sous « Lumière », le bloc « Détails avancés » permet de décrire l'image beaucoup plus finement : éléments à faire apparaître (avec leur position), couleurs, composition (profondeur, plans, symétrie), éclairage (source, direction, qualité, température, ombres), décor, atmosphère, textes présents, rendu et matières, mouvement. Rien n'est obligatoire : le bloc est replié tant que vous ne l'ouvrez pas, et il s'ouvre tout seul quand il contient quelque chose (modèle ou JSON importé).

La description complète est limitée à 4 000 caractères : au-delà, ImagActif vous le dit avant d'envoyer quoi que ce soit à BFL, sans décompter votre quota.

À ne jamais écrire dans la description : le nom d'un élève, sa photo, ou toute information qui permettrait de l'identifier. Ce texte est envoyé à BFL.

3. Le JSON : garder, copier, importer

Chaque image garde la description qui l'a produite, sous forme de texte structuré (le JSON). Vous n'avez pas besoin de le lire pour utiliser l'outil.

  • Copier : le bouton « Copier le JSON » (sur la page Créer ou sur une carte de l'Historique) place la description dans votre presse-papiers, pour la ranger ailleurs ou la réutiliser dans une autre IA.
  • Importer : dans « JSON : copier ou importer », collez un JSON puis « Charger ce JSON ». Il est vérifié, puis rempli dans le formulaire. Les champs que l'outil ne connaît pas sont rangés dans les champs personnalisés. Rien n'est exécuté.
  • Conservation : le JSON reste dans votre Historique tant que vous ne supprimez pas l'image, même quand l'image elle-même a disparu.

Partir d'une image que vous avez déjà

Pour retrouver le style, le cadrage, l'éclairage, l'atmosphère et les textes d'une image existante, faites-la décrire par une IA qui lit les images (Claude, ChatGPT…) dans le format d'ImagActif :

  1. Dans « JSON : copier, importer, ou partir d'une image », cliquez sur Copier la consigne.
  2. Dans votre IA, joignez l'image et collez la consigne.
  3. Collez la réponse (même entourée d'une phrase ou d'un bloc de code) dans « JSON à importer », puis Charger ce JSON.
  4. Relisez et corrigez dans le formulaire : l'IA peut se tromper ou oublier un détail. L'image décrite remplit surtout la section « Détails avancés » (éléments, couleurs, éclairage, décor, atmosphère, textes présents…).
Attention : l'image est envoyée à l'IA que vous choisissez, pas à ImagActif. N'y joignez aucune photo d'élève ni d'image dont vous n'avez pas les droits. Une nouvelle image créée à partir de ce JSON ressemblera à l'originale sans en être une copie, et les textes de l'image d'origine ne sont pas reproduits de façon fiable.

4. Variante et modèle

  • Faire une variante : le formulaire se préremplit avec la description de l'image. Changez ce que vous voulez et cliquez sur « Créer l'image ».
  • Enregistrer comme modèle : donnez un nom (par exemple « Fiche sciences P3, style plat »). Dans l'onglet Modèles, cochez les champs à verrouiller : quand vous utilisez ce modèle, ces champs ne peuvent plus être modifiés (le style, par exemple, pour garder des images cohérentes d'une fiche à l'autre).
  • Graine : un nombre transmis à l'IA pour orienter son tirage. Voir « Ce que l'outil ne fait pas bien » ci-dessous.

5. Combien de temps les images restent

  • Une image est supprimée automatiquement 30 jours après sa création. Le compte à rebours est affiché sur chaque carte, et passe en orange à 5 jours de l'échéance.
  • Pour garder une image : bouton Télécharger, avant l'échéance.
  • Après suppression, la carte reste avec la mention « Image supprimée le … » et un bouton Refaire une image qui repart du même JSON.

6. Votre clé BFL personnelle

  1. Créez un compte sur le site de Black Forest Labs (BFL) et ajoutez des crédits. Une image coûte quelques centimes ; consultez le tarif sur le site de BFL.
  2. Dans votre espace BFL, créez une clé d'API et copiez-la (aide officielle : help.bfl.ai).
  3. Dans ImagActif, onglet Mes données, collez-la dans « Ma clé BFL » et enregistrez.

La clé est stockée chiffrée sur nos serveurs et ne revient jamais dans votre navigateur. Seul notre serveur l'utilise, pour vos images. Le bouton « Supprimer ma clé » la retire à tout moment.

7. Vos données

  • Envoyé à BFL (société allemande, point d'accès européen) : uniquement le texte de la description, pour fabriquer l'image. BFL indique dans sa politique de confidentialité pouvoir utiliser les textes envoyés et les images produites pour améliorer ses modèles, après dé-identification, sauf demande d'exclusion. Elle ne précise ni la durée de conservation ni le lieu exact de traitement. Une demande d'exclusion a été envoyée à BFL le 8 octobre 2026 pour le compte utilisé pendant l'essai ; BFL ne l'a pas encore confirmée. Pour demander l'exclusion de cet usage pour votre propre compte BFL (si vous utilisez votre clé), écrivez à privacy@blackforestlabs.ai avec l'objet « Training Opt Out » et les références de votre compte.
  • Conservé chez nous : votre e-mail (connexion), vos JSON, vos modèles, vos images pendant 30 jours, et votre clé BFL chiffrée si vous l'ajoutez.
  • Exporter : « Mes données », puis « Télécharger mon export » : un fichier ZIP avec vos JSON, vos modèles et les images encore disponibles.
  • Supprimer : « Mes données », puis « Supprimer mes données ImagActif » (confirmation par saisie). Images, JSON, modèles et clé disparaissent aussitôt d'ImagActif ; les copies de sauvegarde de la base (sans les images) sont purgées au plus tard 30 jours plus tard. Seuls restent la date de début de votre essai et le nombre d'images du jour, pour que l'essai ne puisse pas être renouvelé. Votre identifiant de connexion est commun à plusieurs outils PLAI : pour le faire supprimer, écrivez à jf.beguin@outlook.com.

Ce que l'outil ne fait pas bien

  • Le texte dans l'image n'est pas fiable. Lors de nos essais, deux aquarelles ont reçu une fausse signature manuscrite malgré « pas de texte dans l'image ». La rubrique « À éviter » est une demande, pas une garantie.
  • Une même description ne redonne pas la même image. Avec la même graine, le sujet et le style restent proches, mais le cadrage et le décor changent.
  • Une variante peut changer plus que prévu. Lors de nos essais, changer uniquement la palette a aussi modifié la composition. Les champs verrouillés d'un modèle garantissent que le texte de la description ne change pas, pas que l'image reste identique.
  • L'IA peut se tromper : détails faux, objets déformés, mains ou visages étranges, situations qui ne correspondent pas à votre classe. Relisez chaque image avant de l'utiliser avec des élèves.
  • Des descriptions voisines risquent de donner des images voisines : c'est votre contexte, vos mots précis et votre relecture qui donnent à l'image sa singularité. Plus vous êtes concret (objets, couleurs, cadrage), moins le résultat est générique.
